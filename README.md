A curated collection of six fundamental frontend mini-projects built with **HTML5**, **CSS3**, and **vanilla JavaScript**. These projects focus on core browser APIs, dynamic DOM manipulation, state handling, asynchronous API consumption, and interactive event-driven UI design.

---

## 🗂️ Project Catalog

| # | Project Name | Directory | Key Concepts Demonstrated | Description |
|---|---|---|---|---|
| 1 | **Calculator** | [`calculator/`](./calculator/) | Math parsing, input sanitization, event handling | Arithmetic calculator supporting multi-digit operations, decimal precision, and reset. |
| 2 | **Weather App** | [`weather-app/`](./weather-app/) | Async/Await, Fetch API, JSON parsing, error states | Weather search app retrieving and displaying live city temperatures and weather icons. |
| 3 | **Todo List** | [`todo-list/`](./todo-list/) | DOM nodes, item deletion, event listeners | Interactive task manager allowing users to add and remove daily tasks in real time. |
| 4 | **Random Quote Generator** | [`random-quote-generator/`](./random-quote-generator/) | Array indexing, random number generation | Generates and cycles through inspirational quotes with responsive layout. |
| 5 | **Dark Theme Toggle** | [`dark-theme-toggle/`](./dark-theme-toggle/) | CSS variables, class toggling, UI states | Clean dark/light theme switch demonstrating contrast modes and color transitions. |
| 6 | **Background Color Picker** | [`background-color-picker/`](./background-color-picker/) | Color generation, inline DOM style mutation | Interactive background color changer providing instant visual palette feedback. |

## 💻 How to Run Any Project

Each project is fully self-contained and zero-dependency.

### Run Directly in Browser
Navigate into any project directory and open its `index.html` file in your browser:
```bash
# Example: Running the Calculator
cd calculator
open index.html   # macOS
```

### Run via Local Web Server
```bash
# From the root directory:
python3 -m http.server 8080
```
Open `http://localhost:8080` and click into any project folder.
